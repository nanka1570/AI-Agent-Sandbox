# 2D Fantasy Platformer

ファンタジー世界を舞台にした2Dアクションプラットフォーマー。
3つのステージを攻略してゴールを目指す。

## 操作方法

| キー | アクション |
|------|----------|
| ← → / A D | 移動 |
| Space | ジャンプ / 壁ジャンプ / 決定 |
| Z / J | 攻撃（剣） |
| Shift / L | ダッシュ |
| Esc | ポーズ |
| ↑ ↓ / W S | メニュー選択 |

## ビルド方法

### 必要な環境

- C++17 対応コンパイラ
- CMake 3.16 以上
- SFML 2.5 以上

### ビルド手順

```bash
mkdir build && cd build
cmake ..
make
```

### 実行

```bash
./2d-platformer
```
