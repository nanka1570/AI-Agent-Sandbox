## 次のアクション

**→ フェーズ1-1 から開始：Gemini（Antigravity）にキャラクターデザインの方向性を相談する**

Antigravityに渡すプロンプト例：

```
このプロジェクトは2Dファンタジープラットフォーマーゲームです。
デフォルメスタイル（2Dイラスト）でキャラクターをデザインしたいです。

- ジャンル: ファンタジー（冒険・魔法）
- プレイヤー: 冒険者（剣と魔法を使う）
- グラフィック: デフォルメ（2〜3等身のかわいいスタイル）
- 解像度: 32x32pxタイルベース、内部解像度640x360

まず、キャラクターのデフォルメスタイルの方向性を3パターン提案してください。
各パターンで等身、線の太さ、色使いの方向性を示してください。
```
