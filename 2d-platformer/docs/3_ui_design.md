# UI / HUD デザイン仕様

## ビジュアルコンセプト
- **スタイル**: **ソフトポップ・ベクトル UI** (Soft Pop Vector UI)。
- **一貫性**: "美少女マスコット" キャラや "ソフトポップ" 環境スタイルに合わせる。
- **色彩**:
  - **ベース**: 白/クリーム色 (`#FFFDD0`) または 半透明黒 (`#00000080`)。
  - **アクセント**: ゴールド (`#FFD700`), ロイヤルブルー (`#4169E1`)。
  - **テキスト**: 焦げ茶 (`#4A3B32`) または 白に太い縁取り。
- **フォント**: 丸いピクセルフォント または 丸ゴシック (例: "M+ Rounded", "PixelMplus")。

## 1. タイトル画面 (Title Screen)
### レイアウト
```
+--------------------------------------------------+
|  [背景: 森ステージ 昼 (少しボカす)]                |
|                                                  |
|          __  __       _____                      |
|         |  \/  |     |  ___|                     |
|         | |\/| |     | |_                        |
|         |_|  |_|     |_|                         |
|      (ファンタジー・プラットフォーマー ロゴ)        |
|                                                  |
|              ▶  GAME START                       |
|                 EXIT GAME                        |
|                                                  |
|          (c) 2026 AI Agent Team                  |
+--------------------------------------------------+
```
### アセット
- **ロゴ**: カラフルで弾むような文字。「ファンタジー」は金/オレンジ、「美少女」風スタイル。
- **ボタン**:
  - **通常**: シンプルな白い角丸長方形に茶色のテキスト。
  - **ホバー/アクティブ**: 金色の枠線、少し拡大、左にアイコン(剣など)が出る。

### プロンプト (ロゴ)
```text
game logo design, text "Fantasy Adventure", cute colorful vector style, gold and blue gradient, rounded bold typography, sticker style, white background
```

```
|                                                  |
|                                                  |
|             (ゲーム画面)                          |
|                                                  |
+--------------------------------------------------+
```
### アセット
- **HPアイコン**:
  - **ハート(満)**: ハイライトのある赤い艶やかなハート。
  - **ハート(空)**: 灰色のくすんだハートの器。
  - **サイズ**: 16x16px または 24x24px スケール。
- **フォント**: 視認性の高い白文字に焦げ茶の縁取り。

### プロンプト (アイコン)
```text
game ui icon set, pixel art vector style, red heart full, grey heart empty, sword icon, shield icon, potion bottle, cute simple sticker style, white background
```

## 4. リザルト画面 (Result Screen)
### レイアウト
```
+--------------------------------------------------+
|          [暗いオーバーレイ 50%]                    |
|                                                  |
|           STAGE CLEAR !!                         |
|         (紙吹雪エフェクト)                         |
|                                                  |
|        [ Next Stage ]                            |
|        [ Retry      ]                            |
|        [ Title      ]                            |
|                                                  |
+--------------------------------------------------+
```
### アセット
- **クリアテキスト**: 大きな金/虹色のグラデーションテキスト。カーブしている。
- **ゲームオーバーテキスト**: 濃い紫/青の "Game Over" テキスト。涙やお化けのアイコン付き。
- **パネル**: 標準的なメニュー項目のためのシンプルな装飾ウィンドウ枠。
