## §1 クレジットカード管理

### 1.1 画面項目定義

#### 一覧画面（/credit-cards）

| 要素 | 表示内容 | 備考 |
|------|---------|------|
| ページタイトル | 「クレジットカード管理」 | h1 |
| 新規登録ボタン | 「+ 新規登録」 | 右上配置、Dialog を開く |
| カードリスト | カード形式で一覧表示 | shadcn/ui Card |
| 各カード内容 | カード名、締め日、支払い日、メモ | - |
| 編集ボタン | Pencil アイコン | 各カード内 |
| 削除ボタン | Trash2 アイコン、variant="destructive" | 各カード内 |
| 空状態 | EmptyState コンポーネント | カード0件時 |

#### 登録ダイアログ

| フィールド名 | 項目名 | 型 | 必須 | 初期値 | プレースホルダー | バリデーション |
|-------------|-------|-----|------|-------|---------------|-------------|
| name | カード名 | text | ○ | "" | "楽天カード" | 1〜50文字 |
| closingDay | 締め日 | number | ○ | "" | "1〜31" | 1〜31の整数 |
| paymentDay | 支払い日 | number | ○ | "" | "1〜31" | 1〜31の整数 |
| memo | メモ | textarea | - | "" | "メモ（任意）" | - |

#### 編集ダイアログ

登録ダイアログと同一レイアウト。初期値に既存データをセット。タイトルは「クレジットカード編集」、ボタンは「更新する」。

### 1.2 動作仕様

#### 登録フロー

```
1. 「+ 新規登録」ボタンをクリック
2. Dialog が開く（フォームは空）
3. 各項目を入力
4. 「登録する」ボタンをクリック
5. クライアント側 Zod バリデーション実行
   - エラー → フィールド直下にエラーメッセージ表示、処理中断
   - OK → 6へ
6. ボタンを disabled にする（二重送信防止）
7. createCreditCard Server Action を呼び出す
8. 結果判定
   - success: true → トースト「登録しました」、Dialog を閉じる
   - success: false → トースト（エラーメッセージ）、ボタンを再度有効にする
```

#### 編集フロー

```
1. カードの編集ボタンをクリック
2. Dialog が開く（既存データがフォームにセットされている）
3. 項目を変更
4. 「更新する」ボタンをクリック
5. Zod バリデーション → updateCreditCard Server Action
6. 結果判定（登録フローと同じ）
```

#### 削除フロー

```
1. カードの削除ボタンをクリック
2. AlertDialog が開く
   - タイトル: 「このクレジットカードを削除しますか？」
   - 説明: 「このカードに紐づく支払いデータも全て削除されます。この操作は取り消せません。」
3. 「削除する」ボタンをクリック（variant="destructive"）
4. deleteCreditCard Server Action を呼び出す
5. 結果判定
   - success: true → トースト「削除しました」
   - success: false → トースト（エラーメッセージ）
```

### 1.4 Server Actions 詳細

ファイル: `src/lib/actions/credit-card.ts`

#### createCreditCard

```typescript
"use server";

import { revalidatePath } from "next/cache";
import { prisma } from "@/lib/db";
import { creditCardSchema, type CreditCardInput } from "@/types";

type ActionResult<T> =
  | { success: true; data: T }
  | { success: false; error: string };

export async function createCreditCard(
  input: CreditCardInput
): Promise<ActionResult<CreditCard>> {
  // 1. サーバー側バリデーション
  const parsed = creditCardSchema.safeParse(input);
  if (!parsed.success) {
    return { success: false, error: parsed.error.errors[0].message };
  }

  // 2. DB登録
  const card = await prisma.creditCard.create({
    data: {
      name: parsed.data.name,
      closingDay: parsed.data.closingDay,
      paymentDay: parsed.data.paymentDay,
      memo: parsed.data.memo ?? null,
    },
  });

  // 3. キャッシュ無効化
  revalidatePath("/credit-cards");
  revalidatePath("/");

  return { success: true, data: card };
}
```

#### updateCreditCard

```typescript
export async function updateCreditCard(
  id: string,
  input: CreditCardInput
): Promise<ActionResult<CreditCard>> {
  // 1. サーバー側バリデーション
  const parsed = creditCardSchema.safeParse(input);
  if (!parsed.success) {
    return { success: false, error: parsed.error.errors[0].message };
  }

  // 2. 存在確認 + 更新
  const existing = await prisma.creditCard.findUnique({ where: { id } });
  if (!existing) {
    return { success: false, error: "クレジットカードが見つかりません" };
  }

  const card = await prisma.creditCard.update({
    where: { id },
    data: {
      name: parsed.data.name,
      closingDay: parsed.data.closingDay,
      paymentDay: parsed.data.paymentDay,
      memo: parsed.data.memo ?? null,
    },
  });

  revalidatePath("/credit-cards");
  revalidatePath("/");

  return { success: true, data: card };
}
```

#### deleteCreditCard

```typescript
export async function deleteCreditCard(
  id: string
): Promise<ActionResult<void>> {
  // 1. 存在確認
  const existing = await prisma.creditCard.findUnique({ where: { id } });
  if (!existing) {
    return { success: false, error: "クレジットカードが見つかりません" };
  }

  // 2. 削除（CascadeでPaymentも削除される）
  await prisma.creditCard.delete({ where: { id } });

  revalidatePath("/credit-cards");
  revalidatePath("/payments");
  revalidatePath("/");

  return { success: true, data: undefined };
}
```

### 3.2 動作仕様

#### 登録・編集・削除フロー

クレカ管理と同一パターン。
- 登録: createPayment → revalidatePath("/payments") + revalidatePath("/")
- 編集: updatePayment → 同上
- 削除: AlertDialog確認「この支払いデータを削除しますか？」→ deletePayment → 同上

#### ステータス変更フロー

```
1. テーブル内のステータスバッジをクリック
2. 遷移先ステータスを判定
   - unconfirmed → confirmed
   - confirmed → paid
   - paid → 何もしない（クリック無効）
3. updatePaymentStatus Server Action を呼び出す
4. 結果判定
   - success: true → バッジが新しいステータスに更新される
   - success: false → トースト（エラーメッセージ）
```

#### ステータス遷移図

```
unconfirmed ──→ confirmed ──→ paid
  (未確定)       (確定)       (支払い済み)

※ 逆方向への遷移は不可
※ paid からの遷移は不可
```

#### updatePaymentStatus

```typescript
// ステータス遷移マップ
const STATUS_TRANSITIONS: Record<string, string | null> = {
  unconfirmed: "confirmed",
  confirmed: "paid",
  paid: null, // 遷移不可
};

export async function updatePaymentStatus(
  id: string
): Promise<ActionResult<Payment>> {
  const existing = await prisma.payment.findUnique({ where: { id } });
  if (!existing) {
    return { success: false, error: "支払いデータが見つかりません" };
  }

  const nextStatus = STATUS_TRANSITIONS[existing.status];
  if (!nextStatus) {
    return { success: false, error: "これ以上ステータスを変更できません" };
  }

  const payment = await prisma.payment.update({
    where: { id },
    data: { status: nextStatus },
    include: { creditCard: true },
  });

  revalidatePath("/payments");
  revalidatePath("/");

  return { success: true, data: payment };
}
```

## §4 ダッシュボード

### 4.1 収支サマリーカード

3枚のカードで当月の収支を表示する。**全ステータスの支払いを集計対象とする**（未確定金額もリアルタイムで反映）。

#### カード1: 給料合計

```
┌─────────────────────┐
│ 💰 給料合計          │
│ ¥250,000            │
└─────────────────────┘
```

集計: 指定月の `Salary.amount` の合計

#### カード2: 支払い合計（内訳付き）

```
┌─────────────────────┐
│ 💳 支払い合計        │
│ ¥120,000            │
│ 確定 ¥50,000        │
│ 未確定 ¥70,000      │
│ 支払済 ¥0           │
└─────────────────────┘
```

集計: 指定月の `Payment.amount` の合計（**全ステータス**）。ステータス別の内訳を小文字で表示。

#### カード3: 残額

```
┌─────────────────────┐
│ 📊 残額             │
│ ¥130,000            │
│ （確定分残額 ¥200,000）│
└─────────────────────┘
```

集計:
- 残額 = 給料合計 - 支払い合計（全ステータス）
- 確定分残額 = 給料合計 - (confirmed + paid の合計) ← 参考値として小文字で表示

### 4.2 集計ロジック

ファイル: `src/app/page.tsx`（Server Component 内で直接計算）

```typescript
  include: { creditCard: true },
});
const totalPayment = payments.reduce((sum, p) => sum + p.amount, 0);

// ステータス別集計
const statusBreakdown = {
  unconfirmed: payments
    .filter((p) => p.status === "unconfirmed")
    .reduce((sum, p) => sum + p.amount, 0),
  confirmed: payments
    .filter((p) => p.status === "confirmed")
    .reduce((sum, p) => sum + p.amount, 0),
  paid: payments
    .filter((p) => p.status === "paid")
    .reduce((sum, p) => sum + p.amount, 0),
};

// 残額計算
const balance = totalSalary - totalPayment;
const confirmedBalance = totalSalary - (statusBreakdown.confirmed + statusBreakdown.paid);
```
