## 1. テスト方針

### 1.1 目的

家計簿アプリの全機能が要件定義書・設計書通りに動作することを検証する。

### 1.2 基本方針

- 単体テスト + コンポーネントテストで個々の機能を検証
- E2Eテストで主要なユーザーフローを検証
- テスト仕様書（07_テスト仕様書）に基づいてテストを作成・実行する
- テストは詳細設計フェーズで仕様書を作成し、テストフェーズで実装・実行する

---

## 2. テスト種類

| テスト種類 | ツール | 対象 | 配置先 |
|-----------|--------|------|--------|
| 単体テスト | Vitest | Server Actions、ユーティリティ関数、Zodスキーマ | `__tests__/` |
| コンポーネントテスト | Vitest + React Testing Library | UIコンポーネントの表示・操作 | `__tests__/` |
| E2Eテスト | Playwright | ユーザーフロー全体 | `e2e/` |

### 2.1 単体テスト

Server Actions の入出力、バリデーションロジック、ユーティリティ関数を対象とする。

**テスト対象:**
- `src/lib/actions/credit-card.ts` — クレカCRUD操作
- `src/lib/actions/salary.ts` — 給料CRUD操作
- `src/lib/actions/payment.ts` — 支払いCRUD操作 + ステータス変更
- `src/types/index.ts` — Zodバリデーションスキーマ

### 2.2 コンポーネントテスト

UIコンポーネントが正しくレンダリングされ、ユーザー操作に応答することを検証する。

**テスト対象:**
- フォームコンポーネント（バリデーションエラー表示、送信処理）
- 一覧表示コンポーネント（データ表示、空状態）
- ステータスバッジ（表示、クリック動作）
- グラフコンポーネント（レンダリング確認）

### 2.3 E2Eテスト

ブラウザ上で実際のユーザーフローを再現し、全体が正しく動作することを検証する。

**テスト対象フロー:**
1. クレカ登録 → 支払い登録 → ダッシュボード確認
2. 給料登録 → ダッシュボード確認
3. 支払いステータス変更 → ダッシュボード更新確認

## 3. テスト環境

| 項目 | 内容 |
|------|------|
| テストランナー | Vitest 4.x |
| DOM環境 | jsdom |
| コンポーネントテスト | @testing-library/react 16.x |
| マッチャー | @testing-library/jest-dom |
| E2Eテスト | Playwright (Phase 5b でセットアップ) |
| カバレッジ | @vitest/coverage-v8 |
| DB | SQLite（テスト用dev.db） |

### テスト実行コマンド

| コマンド | 用途 |
|---------|------|
| `npm run test` | 単体テスト + コンポーネントテスト（1回実行） |
| `npm run test:watch` | ウォッチモード（開発時） |
| `npm run test:coverage` | カバレッジ付きテスト実行 |
| `npx playwright test` | E2Eテスト実行 |

### テスト設定ファイル

| ファイル | 用途 |
|---------|------|
| `vitest.config.mts` | Vitest 設定（jsdom環境、パスエイリアス、カバレッジ） |
| `src/test/setup.ts` | テスト共通設定（jest-dom マッチャー読み込み） |

## 4. テストスコープ

### 4.1 テスト対象（IN SCOPE）

| 機能 | 単体テスト | コンポーネントテスト | E2Eテスト |
|------|-----------|-------------------|----------|
| クレカ管理CRUD | ✅ | ✅ | ✅ |
| 給料管理CRUD | ✅ | ✅ | ✅ |
| 支払い管理CRUD | ✅ | ✅ | ✅ |
| ステータス変更 | ✅ | ✅ | ✅ |
| ダッシュボード集計 | ✅ | ✅ | ✅ |
| Zodバリデーション | ✅ | — | — |
| グラフ描画 | — | ✅（レンダリング確認） | — |

### 4.2 テスト対象外（OUT OF SCOPE）

| 項目 | 理由 |
|------|------|
| 認証・認可 | MVPでは未実装 |
| パフォーマンステスト | MVPでは不要 |
| クロスブラウザテスト | Chrome最新版のみ対象 |
| アクセシビリティテスト | MVP後に対応 |
| 負荷テスト | ローカルSQLiteのため不要 |
