# 全エラー一括修正

## 手順

1. `CLAUDE.md` を読み、コーディング規約を確認する
2. 以下のコマンドを順に実行し、エラーを収集する:
   - `npx tsc --noEmit 2>&1` で型エラーを確認
   - `npm run lint 2>&1` でリントエラーを確認
   - `npm run build 2>&1` でビルドエラーを確認
   - `npm run test 2>&1` でテストエラーを確認（テストが存在する場合）
3. 全エラーを一覧化する
4. エラーを1つずつ修正する（型エラー → リント → ビルド → テスト の順）
5. 全て修正後、再度全コマンドを実行して全てPASSすることを確認する
6. 修正内容をサマリーで報告する
