## §6 E2Eテストケース

テストファイル: `e2e/` ディレクトリ

### E2E-001: クレカ登録 → 支払い登録 → ダッシュボード確認

テストファイル: `e2e/credit-card-payment-flow.spec.ts`

```
前提条件: データベースが空の状態

手順:
1. /credit-cards にアクセス
2. 「新規登録」ボタンをクリック
3. カード名「テストカード」、締め日「15」、支払い日「10」を入力
4. 「登録する」をクリック
5. トースト「登録しました」が表示されることを確認
6. カード一覧に「テストカード」が表示されることを確認

7. /payments にアクセス
8. 「新規登録」ボタンをクリック
9. クレジットカード「テストカード」を選択
10. 対象月に現在月、金額「50000」を入力
11. 「登録する」をクリック
12. トースト「登録しました」が表示されることを確認
13. テーブルに「テストカード」「¥50,000」「未確定」が表示されることを確認

14. / (ダッシュボード) にアクセス
15. 支払い合計カードに「¥50,000」が表示されることを確認
16. 内訳に「未確定 ¥50,000」が表示されることを確認
```

### E2E-002: 給料登録 → ダッシュボード確認

テストファイル: `e2e/salary-dashboard-flow.spec.ts`

```
前提条件: データベースが空の状態

手順:
1. /salary にアクセス
2. 「新規登録」ボタンをクリック
3. 対象月に現在月、支給日「25」、手取り額「250000」を入力
4. 「登録する」をクリック
5. トースト「登録しました」が表示されることを確認
6. テーブルに「¥250,000」が表示されることを確認

7. / (ダッシュボード) にアクセス
8. 給料合計カードに「¥250,000」が表示されることを確認
9. 残額カードに「¥250,000」が表示されることを確認（支払いなし）
```

### E2E-003: 支払いステータス変更 → ダッシュボード更新確認

テストファイル: `e2e/status-change-flow.spec.ts`

```
前提条件: クレカ1枚と支払い1件（status=unconfirmed, amount=50000）が登録済み

手順:
1. /payments にアクセス
2. 「未確定」バッジが表示されていることを確認
3. 「未確定」バッジをクリック
4. バッジが「確定」（青）に変わることを確認

5. / (ダッシュボード) にアクセス
6. 支払い合計の内訳で「確定 ¥50,000」が表示されることを確認

7. /payments に戻る
8. 「確定」バッジをクリック
9. バッジが「支払い済み」（緑）に変わることを確認

10. / (ダッシュボード) にアクセス
11. 支払い合計の内訳で「支払済 ¥50,000」が表示されることを確認
```
