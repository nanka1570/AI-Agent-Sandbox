## 1. 概要

家計簿アプリのデータベース設計。MVP段階では Prisma + SQLite を使用し、Phase B で Supabase PostgreSQL に移行予定。

### 技術選定
- ORM: Prisma 7.x
- DB: SQLite（MVP）→ PostgreSQL（Phase B）
- マイグレーション: Prisma Migrate

---

## 2. ER図（テキスト表現）

```
Salary
  └─ (独立テーブル)

CreditCard ──< Payment
  └─ 1:N リレーション（onDelete: Cascade）
```

## 3. テーブル定義

### 3.1 Salary（給料）

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|----------|------|
| id | TEXT (cuid) | NOT NULL | cuid() | 主キー |
| payDay | INTEGER | NOT NULL | - | 支給日（1-31） |
| amount | INTEGER | NOT NULL | - | 手取り額（円） |
| month | TEXT | NOT NULL | - | 対象月 "YYYY-MM" |
| memo | TEXT | NULL | - | メモ |
| createdAt | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 作成日時 |
| updatedAt | DATETIME | NOT NULL | - | 更新日時（自動更新） |

### 3.2 CreditCard（クレジットカード）

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|----------|------|
| id | TEXT (cuid) | NOT NULL | cuid() | 主キー |
| name | TEXT | NOT NULL | - | カード名 |
| closingDay | INTEGER | NOT NULL | - | 締め日（1-31） |
| paymentDay | INTEGER | NOT NULL | - | 支払い日（1-31） |
| memo | TEXT | NULL | - | メモ |
| createdAt | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 作成日時 |
| updatedAt | DATETIME | NOT NULL | - | 更新日時（自動更新） |

**リレーション:** Payment テーブルと 1:N の関係

### 3.3 Payment（支払い）

| カラム名 | 型 | NULL | デフォルト | 説明 |
|---------|-----|------|----------|------|
| id | TEXT (cuid) | NOT NULL | cuid() | 主キー |
| creditCardId | TEXT | NOT NULL | - | クレカID（外部キー） |
| month | TEXT | NOT NULL | - | 対象月 "YYYY-MM" |
| amount | INTEGER | NOT NULL | - | 確定金額（円） |
| status | TEXT | NOT NULL | "unconfirmed" | ステータス |
| memo | TEXT | NULL | - | メモ |
| createdAt | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 作成日時 |
| updatedAt | DATETIME | NOT NULL | - | 更新日時（自動更新） |

**外部キー:** creditCardId → CreditCard.id（ON DELETE CASCADE）

### ステータス値

| 値 | 表示名 | 説明 |
|----|-------|------|
| unconfirmed | 未確定 | クレカ請求額が未確定 |
| confirmed | 確定 | クレカ請求額が確定した |
| paid | 支払い済み | 引き落とし完了 |

## 4. Prisma スキーマ

```prisma
generator client {
  provider = "prisma-client"
  output   = "../src/generated/prisma"
}

datasource db {
  provider = "sqlite"
}

model Salary {
  id        String   @id @default(cuid())
  payDay    Int
  amount    Int
  month     String
  memo      String?
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}

model CreditCard {
  id         String    @id @default(cuid())
  name       String
  closingDay Int
  paymentDay Int
  memo       String?
  createdAt  DateTime  @default(now())
  updatedAt  DateTime  @updatedAt
  payments   Payment[]
}

model Payment {
  id           String     @id @default(cuid())
  creditCardId String
  creditCard   CreditCard @relation(fields: [creditCardId], references: [id], onDelete: Cascade)
  month        String
  amount       Int
  status       String     @default("unconfirmed")
  memo         String?
  createdAt    DateTime   @default(now())
  updatedAt    DateTime   @updatedAt
}
```
