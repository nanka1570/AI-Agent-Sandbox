**ダッシュボードのセクション順序:**
1. サマリーカード3枚（手取り合計・支払い合計・残額）
2. 引き落とし予定テーブル（カードごとに折りたたみ）
3. 資金繰りサマリー（手取り入金日との前後関係）
4. 予算消化率
5. グラフ（月別支出推移 + カテゴリ別支出）
6. 広告スペース

**クイック入力FAB（右下固定）:**
- モバイル/デスクトップ共通、右下に常時表示
- タップでダイアログを開き、支払いをクイック登録

## 5. レスポンシブ方針

### 5.1 ブレークポイント

Tailwind CSS v4 のデフォルトブレークポイントを使用:

| 名前 | 画面幅 | 用途 |
|------|--------|------|
| sm | 640px〜 | 小画面調整 |
| md | 768px〜 | モバイル/デスクトップ切り替え |
| lg | 1024px〜 | ワイド表示 |

### 5.2 レスポンシブ対応の具体的方針

| 要素 | デスクトップ | モバイル |
|------|------------|---------|
| ナビゲーション | ヘッダー内リンク | BottomNav（下部固定） |
| サマリーカード | 横3列（grid-cols-3） | 横1列（grid-cols-1） |
| グラフ | 横2列配置 | 縦1列配置 |
| テーブル | テーブル表示 | テーブル表示（横スクロール） |
| ダイアログ | 中央モーダル（max-w-md） | ほぼフルスクリーン |
| クイック入力FAB | 右下固定表示 | 右下固定表示 |
| レポート月次詳細 | 横3列グリッド | 横1列 |
