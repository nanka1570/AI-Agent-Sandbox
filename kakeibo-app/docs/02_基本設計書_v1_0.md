## 3. Server Actions 一覧

### 3.1 クレカ管理 (`src/lib/actions/credit-card.ts`)

| アクション名 | 操作 | 入力 | 出力 | エラー |
|-------------|------|------|------|--------|
| createCreditCard | 登録 | { name, closingDay, paymentDay, memo? } | CreditCard | Zodバリデーションエラー |
| updateCreditCard | 編集 | { id, name, closingDay, paymentDay, memo? } | CreditCard | 対象なしエラー、Zodバリデーションエラー |
| deleteCreditCard | 削除 | { id } | void | 対象なしエラー |

### 3.2 給料管理 (`src/lib/actions/salary.ts`)

| アクション名 | 操作 | 入力 | 出力 | エラー |
|-------------|------|------|------|--------|
| createSalary | 登録 | { payDay, amount, month, memo? } | Salary | Zodバリデーションエラー |
| updateSalary | 編集 | { id, payDay, amount, month, memo? } | Salary | 対象なしエラー、Zodバリデーションエラー |
| deleteSalary | 削除 | { id } | void | 対象なしエラー |

### 3.3 支払い管理 (`src/lib/actions/payment.ts`)

| アクション名 | 操作 | 入力 | 出力 | エラー |
|-------------|------|------|------|--------|
| createPayment | 登録 | { creditCardId, month, amount, memo? } | Payment | Zodバリデーションエラー、クレカ存在チェック |
| updatePayment | 編集 | { id, creditCardId, month, amount, memo? } | Payment | 対象なしエラー、Zodバリデーションエラー |
| deletePayment | 削除 | { id } | void | 対象なしエラー |
| updatePaymentStatus | ステータス変更 | { id, status } | Payment | 対象なしエラー、不正ステータス |

## 4. データ取得方針

### 4.1 Server Components でのデータ取得

各ページの Server Component が直接 Prisma を呼び出してデータを取得する。

| ページ | 取得データ | Prismaクエリ |
|--------|----------|-------------|
| / (ダッシュボード) | 今月の給料一覧、今月の支払い一覧（クレカ情報含む）、直近6ヶ月の支払い集計 | `salary.findMany`, `payment.findMany({ include: { creditCard: true } })` |
| /credit-cards | クレカ一覧 | `creditCard.findMany({ orderBy: { createdAt: 'desc' } })` |
| /salary | 給料一覧 | `salary.findMany({ orderBy: { month: 'desc' } })` |
| /payments | 支払い一覧（月別フィルター付き、クレカ情報含む） | `payment.findMany({ where: { month }, include: { creditCard: true }, orderBy: { createdAt: 'desc' } })` |

### 4.2 データ変更

全てのデータ変更は Server Actions 経由で行う。Server Actions は `"use server"` ディレクティブ付きの関数として定義し、`revalidatePath()` でキャッシュを無効化する。

## 5. 共通仕様

### 5.1 レイアウト

- **ヘッダー**: アプリ名「家計簿」+ ナビゲーションリンク4つ
- **コンテンツエリア**: `max-w-5xl mx-auto px-4 py-6`
- **フォント**: Geist Sans / Geist Mono
- **言語**: `<html lang="ja">`

### 5.2 ナビゲーション

| リンク | パス | アイコン（Phase 4e で追加） |
|--------|------|--------------------------|
| ダッシュボード | / | LayoutDashboard |
| クレカ管理 | /credit-cards | CreditCard |
| 給料管理 | /salary | Wallet |
| 支払い管理 | /payments | Receipt |

### 5.3 エラーハンドリング方針

| エラー種類 | 処理方法 |
|-----------|---------|
| Zodバリデーションエラー | フォーム上にフィールド単位でエラーメッセージ表示 |
| Server Actions のDBエラー | `{ success: false, error: "メッセージ" }` を返し、トースト通知で表示 |
| ページレンダリングエラー | `error.tsx` でキャッチし、リトライボタンを表示 |
| 404 | Next.js デフォルトの not-found ページ |

### 5.4 Server Actions の戻り値形式

```typescript
type ActionResult<T> =
  | { success: true; data: T }
  | { success: false; error: string };
```

全ての Server Actions はこの形式で戻り値を返す。

### 5.5 日付・金額の表示形式

| 項目 | 形式 | 例 |
|------|------|-----|
| 対象月 | YYYY年MM月 | 2026年03月 |
| 金額 | ¥N,NNN | ¥150,000 |
| 日付（日のみ） | N日 | 25日 |
| 作成日時 | YYYY/MM/DD HH:mm | 2026/02/17 14:30 |

## 6. レスポンシブ対応方針

| ブレークポイント | 画面幅 | レイアウト |
|----------------|--------|----------|
| モバイル | 〜767px | BottomNav（下部固定ナビ）、カード縦並び |
| デスクトップ | 768px〜 | ヘッダーナビ、カード横並び（グリッド） |

### モバイル時の変更点
- ヘッダーのナビゲーションリンクを非表示にし、BottomNav を表示
- テーブル表示をカード表示に切り替え（必要に応じて）
- ダイアログはフルスクリーンに近いサイズに拡大
