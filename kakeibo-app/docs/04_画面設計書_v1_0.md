### 3.1 ダッシュボード（/）

```
┌──────────────────────────────────────────────┐
│ ダッシュボード                    [2026年02月 ▼] │
├──────────────────────────────────────────────┤
│                                              │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐    │
│  │  給料合計  │ │ 支払い合計 │ │   残額    │    │
│  │ ¥250,000 │ │ ¥120,000 │ │ ¥130,000 │    │
│  └──────────┘ └──────────┘ └──────────┘    │
│                                              │
│  ┌──────────────────────────────────────┐    │
│  │ 今月の支払い予定                       │    │
│  │ ┌────────┬─────┬────────┬──────────┐ │    │
│  │ │カード名 │ 日  │  金額   │ステータス │ │    │
│  │ ├────────┼─────┼────────┼──────────┤ │    │
│  │ │楽天カード│ 10日│¥50,000 │ 確定     │ │    │

│  │ └────────┴─────┴────────┴──────────┘ │    │
│  └──────────────────────────────────────┘    │
│                                              │
│  ┌─────────────────┐ ┌──────────────────┐   │
│  │ 月別支出推移      │ │ クレカ別支出      │   │
│  │ (棒グラフ)       │ │ (円グラフ)       │   │
│  │  ██              │ │    ┌──┐         │   │
│  │  ██ ██           │ │   /    \        │   │
│  │  ██ ██ ██        │ │  │      │       │   │
│  │ 9月 10月 11月...  │ │   \    /        │   │
│  └─────────────────┘ └──────────────────┘   │
└──────────────────────────────────────────────┘
```

**構成要素:**
- 月選択（現在月がデフォルト）
- 収支サマリーカード3枚（給料合計、支払い合計、残額）
- 今月の支払い予定一覧テーブル
- 月別支出推移グラフ（棒グラフ、直近6ヶ月）
- クレカ別支出グラフ（円グラフ、当月）

## 5. レスポンシブ方針

### 5.1 ブレークポイント

Tailwind CSS v4 のデフォルトブレークポイントを使用:

| 名前 | 画面幅 | 用途 |
|------|--------|------|
| sm | 640px〜 | - |
| md | 768px〜 | モバイル/デスクトップ切り替え |
| lg | 1024px〜 | ワイド表示 |

### 5.2 モバイル対応の具体的方針

| 要素 | デスクトップ | モバイル |
|------|------------|---------|
| ナビゲーション | ヘッダー内リンク | BottomNav（下部固定） |
| サマリーカード | 横3列（grid-cols-3） | 横1列（grid-cols-1） |
| グラフ | 横2列配置 | 縦1列配置 |
| テーブル | テーブル表示 | テーブル表示（横スクロール） |
| ダイアログ | 中央モーダル（max-w-md） | ほぼフルスクリーン |
