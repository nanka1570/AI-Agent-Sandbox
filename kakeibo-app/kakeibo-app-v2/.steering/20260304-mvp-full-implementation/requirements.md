# 要求内容

## 概要

kakeibo-app v2 の MVP 全機能（F-01〜F-06）を新規実装する。Next.js App Router + Supabase + Prisma のプロジェクトスキャフォールディングから、6つのコア機能の実装までを一括で行う。

## 背景

kakeibo-app v2 は PRD・機能設計書・アーキテクチャ設計書等のドキュメントが完成しており、実装フェーズに移行する段階。ソースコードはまだ存在せず、プロジェクトの初期セットアップから開始する必要がある。

## 実装対象の機能

### 0. プロジェクトスキャフォールディング
- Next.js App Router プロジェクトの作成
- 全依存パッケージのインストール
- 設定ファイル（TypeScript, ESLint, Prettier, Vitest, Playwright）の構成
- Prisma スキーマ定義とマイグレーション
- Supabase クライアント設定
- 共通ユーティリティ・型定義の作成

### 1. F-06: 認証
- メール+パスワードによるログイン・新規登録
- パスワードリセット（メール送信）
- ログアウト
- middleware.ts による認証チェックとリダイレクト
- 認証エラーの日本語化

### 2. F-05: カテゴリ管理
- デフォルトカテゴリの自動作成
- カスタムカテゴリの CRUD
- ドラッグ&ドロップによる並び替え
- 「その他」カテゴリの末尾固定

### 3. F-01: クレジットカード管理
- カードの CRUD（名前、締め日、支払い日、支払月オフセット、確定日、ブランド）
- ドラッグ&ドロップによる並び替え
- 削除時のカスケード削除

### 4. F-02: 手取り管理
- 月別の手取り額・給料日・メモの CRUD
- 金額プリセット候補表示
- 月降順表示

### 5. F-03: 支払い管理
- 支払いの CRUD
- ステータス循環遷移（unconfirmed → confirmed → paid → unconfirmed）
- カード単位の一括ステータス変更
- 繰り返し支払い登録（4レコード同時作成）
- 一括登録（2ステップダイアログ）
- カテゴリフィルター・キーワード検索
- 自動ステータス判定

### 6. F-04: ダッシュボード
- 月セレクター
- サマリーカード3枚（手取り合計、支払い合計、残額）
- ステータス別内訳
- 支払い予定テーブル（カード別折りたたみ）
- 資金繰りセクション
- 給料サイクルベースのフィルタリング

## 受け入れ条件

PRD v1.8 の各機能（F-01〜F-06）の受け入れ条件をすべて満たすこと。

## 成功指標

- 全 P0 機能が動作すること
- `npm run lint`, `npm run typecheck`, `npm run build` がエラーなく通ること

## スコープ外

- F-07: 予算管理（Post-MVP）
- F-08: レポート（Post-MVP）
- F-09: PWA対応（Post-MVP）
- F-10: CSVエクスポート（Post-MVP）
- E2Eテスト（別タスクで実施）
- 単体テスト・統合テスト（別タスクで実施）
