# stock-signal-app を自力で作るための教科書

この教科書は、**stock-signal-app（米国テック株シグナルアプリ）と同じものを自分の手で作れるようになる**ための学習教材です。

## 対象読者（前提とする実力）

facility-management-system の Phase 1 を自作できるレベルを前提にします。具体的には:

- Next.js（App Router）で複数画面の CRUD アプリを作れる
- TypeScript と Tailwind CSS の基本が書ける
- DB（Supabase）に対する作成・取得・更新・削除と、重複チェックのようなビジネスルールを実装できる

逆に、以下は**知らない前提**でゼロから説明します:

- Prisma / マイグレーション / SQLite
- 外部 API 連携・キャッシュ・差分同期
- ドメインロジックの純粋関数分離と単体テスト（Vitest）
- E2E テスト（Playwright）
- チャート描画（Recharts）
- LLM（Claude API）連携

## この教科書の使い方

facility-management と同じ学習ワークフローを踏襲します。**見本のコードをコピーしない**こと。

1. 各章を読み、章末の**演習**を自分の手で実装する
2. 詰まったら、章に書かれた「見本」のファイル（この stock-signal-app の実コード）を**読んで理解し、閉じてから**自分のコードに反映する
3. 全章を終えたら、第 9 章の**総合演習**でミニ版アプリをゼロから作る

各章は「学習目標 → facility-management との接続 → 本編 → 見本の場所 → 演習 → 理解度チェック」の構成です。

## 完成物の全体像

## 学習のコツ

- **写経より演習**: コードを写して動いても力にならない。演習を自力で書き、動かなかったら見本と「差分」を探す
- **エラーは教材**: この教科書には、実際の開発中に起きた失敗（型エラー、テストの落ち方、キャッシュの罠）を「実話」として載せている。同じエラーに自分で遭遇したら儲けもの
- **1 章 1 ブランチ**: 演習は git のブランチを切って行い、章が終わったらコミットして振り返る
